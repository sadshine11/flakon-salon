# Флакон: демо-сайт салона красоты

Демо-версия сайта салона «Флакон на Геодезической» (Новосибирск) с онлайн-записью.
Статический сайт без сборки: `index.html`, стили в `assets/css`, данные услуг и мастеров в `assets/js/data.js`.

В демо запись никуда не отправляется, свободное время генерируется в браузере.
